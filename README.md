📊 Smart Sales Performance Analytics and Forecasting
An end-to-end sales analytics mini project that combines SQL, Python, and Power BI to analyze revenue trends, regional and product performance, and forecast future sales using machine learning.


📌 Project Overview
This mini project analyzes sales data to identify revenue trends, regional performance, product performance, and category contribution. It also includes sales forecasting and an interactive Power BI dashboard.

🚀 Getting Started
1. Clone the repository
git clone https://github.com/<your-username>/smart-sales-performance-analytics.git

cd smart-sales-performance-analytics
2. Install Python dependencies
pip install pandas numpy matplotlib seaborn scikit-learn mysql-connector-python
3. Run the Python analysis
python sales_analysis.py
4. Run the SQL analysis
python sql_sales_analysis.py
5. Open the Power BI dashboard
Open Dashboard on Sales Data (mini project).pbix in Power BI Desktop to explore the interactive dashboard.


📈 Outcome
The project provides business insights into sales performance and helps identify trends and patterns that can support better business decision-making — from spotting underperforming regions to forecasting near-term revenue.
